# BabyNote — 宝宝成长记录 Agent 设计文档

## 项目定位

通过飞书 Bot 随时用语音/文字/图片记录宝宝日常，数据存 Obsidian Vault，随时自然语言查询，并自动/手动生成成长报告。

**一句话：** 手机随手记，Obsidian 永久存，随时问，定期看报告。

**用户：** 自己（新手爸妈）

**核心价值：** 一手抱娃一手记录，不漏掉任何成长细节

---

## 架构总览

```
你 (飞书App)
   │
   ▼ 语音/文字/图片
飞书 Bot (Webhook)
   │
   ▼
Middleman Service (Python)
   │
   ├──→ 飞书 ASR（语音转文字）
   ├──→ 飞书 图片API（下载原图）
   ├──→ LLM（解析意图 + 结构化 + 问答）
   └──→ Obsidian Vault（Markdown + 附件存储）
```

**三个核心组件：**

| 组件 | 职责 | 技术 |
|------|------|------|
| 飞书 Bot | 接收消息、发送回复、事件订阅 | 飞书开放平台 Bot |
| Middleman | 意图路由、结构化解析、文件读写 | Python 服务 |
| LLM | 理解自然语言、提取结构化数据、回答查询 | OpenAI GPT-4o / DeepSeek |

## 数据模型

### 文件结构

```
vault/
├── baby/
│   ├── 2026-05-28.md              # 每日记录
│   ├── 2026-05-29.md
│   └── ...
├── baby/reports/
│   ├── daily/
│   │   └── 2026-05-28.md          # 日报
│   ├── weekly/
│   │   └── 2026-W22.md            # 周报
│   └── monthly/
│       └── 2026-05.md              # 月报
├── attachments/
│   ├── baby-2026-05-28-001.jpg
│   └── ...
└── wiki/
    └── ...  (现有知识库不动)
```

### 每日记录格式

```markdown
---
date: 2026-05-28
baby_age: "8个月12天"
---

# 🍼 2026-05-28 宝宝日记

## 吃喝
- 07:30 母乳 15min 左侧
- 10:00 配方奶 120ml
- 12:30 米粉 30g + 南瓜泥
- 15:00 配方奶 90ml
- 18:30 母乳 10min 右侧
- 21:00 配方奶 150ml

## 排泄
- 08:00 尿布湿，黄色软便
- 14:00 换尿布，小便
- 20:30 换尿布，小便

## 睡眠
- 入睡: 21:30
- 夜醒: 01:00, 04:30
- 起床: 06:30

## 身体指标
- 体重: 8.5kg

## 里程碑
- 今天第一次自己扶着沙发站起来了！ ![[baby-2026-05-28-001.jpg]]

## 健康
- 无异常
```

### 设计原则

- 文件即数据，人能直接读、Obsidian 能直接渲染
- Frontmatter 放元数据（日期、月龄），方便后续 Dataview 查询
- 每个维度用 `##` 分隔，LLM 解析和人工浏览都清晰
- 照片用 Obsidian 的 `![[wikilink]]` 语法嵌入，保证双端可看

## 交互流程

### 路径 1：记录（语音/文字/图片）

**文字输入：**
```
你 → 飞书Bot: "宝宝刚吃了120ml奶"
                    │
                    ▼
              LLM 解析意图 → 识别为"记录"
                    │
                    ▼
              提取结构化数据:
              { type: "吃喝", time: "now", content: "配方奶 120ml" }
                    │
                    ▼
              读取/创建当日 baby/2026-05-28.md
              追加到 "## 吃喝" 区块
                    │
                    ▼
              Bot 回复: "✅ 已记录：10:00 配方奶 120ml"
```

**语音输入：**
```
你 → 飞书Bot: 🎤 语音消息 "宝宝八点半吃了一侧母乳大概十五分钟"
                    │
                    ▼
              飞书 ASR 转文字
                    │
                    ▼
              LLM 解析 (同上文字流程)
```

**图片输入：**
```
你 → 飞书Bot: 📷 照片
                    │
                    ▼
              下载图片 → 保存到 attachments/
                    │
                    ▼
              Bot 追问: "这张照片想记在哪个类别？"
              A) 里程碑瞬间 B) 身体指标 C) 只记录照片
                    │
                    ▼
              你回复: "A"
                    │
                    ▼
              追加到对应区块 + 嵌入 ![[baby-2026-05-28-001.jpg]]
              Bot 回复: "✅ 已记录到里程碑"
```

### 路径 2：查询

**当日查询：**
```
你 → 飞书Bot: "宝宝今天吃了多少奶"
                    │
                    ▼
              LLM 解析意图 → 识别为"查询"
                    │
                    ▼
              定位文件: baby/2026-05-28.md
              读取 "## 吃喝" 区块
                    │
                    ▼
              LLM 汇总回答: "今天宝宝共吃了360ml配方奶+2次母乳，具体情况如下..."
```

**跨天查询：**
```
你 → 飞书Bot: "这周宝宝每天睡多久"
                    │
                    ▼
              LLM 定位日期范围 → 读取 7 个文件
              提取各文件的 "## 睡眠" 区块
                    │
                    ▼
              汇总回答: "本周睡眠时长：周一9.5h、周二8h..."
```

### 异常处理

| 情况 | 处理 |
|------|------|
| 意图不明确 | Bot 追问："你是想记录还是想查？" |
| 时间模糊"刚才吃了" | 默认取当前时间，Bot 确认："记在14:30，对吗？" |
| 数据冲突（同一天两次同类型） | 以最后一次为准，旧记录保留但标记更新时间 |
| 图片无分类回复 | 24h 无回复则归入"未分类照片"，下次对话提醒 |

## 定期成长报告

### 报告层级

| 报告 | 生成时机 | 核心内容 |
|------|----------|----------|
| **日报** | 每天 22:00 自动生成 | 吃喝汇总（总奶量/辅食种类）、排泄次数、睡眠时长+夜醒次数、当日照片精选 |
| **周报** | 每周日 22:00 手动触发 | 本周趋势（奶量变化曲线、睡眠规律）、体重变化、新里程碑、与上周对比 |
| **月报** | 每月末 22:00 手动触发 | 发育评估（对比标准发育曲线）、本月里程碑汇总、整体趋势、下月预期 |

### 月报示例

```markdown
---
type: monthly-report
period: 2026-05
baby_age: "8个月"
---

# 📊 2026年5月 宝宝月报

## 🍼 吃喝
- 日均奶量: 680ml (上月 650ml ↑)
- 辅食: 从1餐增加到2餐，新增了南瓜泥、蛋黄
- 奶量趋势: 持续上升，第3周最高

## 😴 睡眠
- 日均睡眠: 10.2h (上月 9.8h ↑)
- 夜醒频率: 均匀下降，从每夜3次→2次
- 最佳睡眠日: 5月12日，11h仅1次夜醒

## 📏 发育指标
- 体重: 8.5kg (月初8.2kg → 月末8.5kg，+300g)
- 本月标准参考: 8个月男宝中位数 8.0kg ✅高于中位

## 🎯 里程碑
✅ 第一次扶站 (5月10日)
✅ 第一次辅食吃蛋黄 (5月18日)

## 📸 本月精选
![[baby-2026-05-10-001.jpg]]
![[baby-2026-05-18-002.jpg]]

## 🔮 下月预期
- 可能开始爬行
- 尝试更多手指食物
- 继续观察夜醒频率是否持续下降
```

### 触发方式

| 方式 | 说明 |
|------|------|
| 自动 | 日报每天 22:00 定时生成 + 飞书推送 |
| 手动 | 飞书发送"生成本月报告"/"今天日报" 立即触发 |

## 技术栈

| 层 | 技术 | 理由 |
|---|---|---|
| Bot 框架 | Python + Feishu SDK (官方) | 飞书 Python SDK 成熟，文档好 |
| LLM | OpenAI GPT-4o / DeepSeek | 支持结构化输出 + 中文理解强 |
| 文件操作 | 直接读写 Markdown | 无需 DB，简单可靠 |
| 部署 | 本地服务 or 轻量云服务器 | 初期自用，不需要高可用 |
| 图片存储 | 本地文件系统（Vault attachments 目录） | Obsidian 直接索引 |

### 飞书 Bot 关键配置

```
事件订阅:
  - im.message.receive_v1   (接收消息)

权限:
  - im:message              (读消息)
  - im:message:send_as_bot  (发消息)
  - im:resource             (下载图片/文件)
  - im:voice                (语音转文字)
```

### LLM Prompt 策略

**意图分类 Prompt（轻量，快速路由）：**
```
用户输入: {raw_text}
判断意图是以下哪种，只返回类别名:
- record: 记录宝宝日常（吃喝/排泄/睡眠/指标/里程碑/健康）
- query:  查询历史记录
- report: 生成成长报告
- photo:  发送了照片需要归类
- unknown: 无法判断
```

**结构化提取 Prompt（仅对 record 类型）：**
```
将以下自然语言提取为结构化数据，输出JSON:
{
  "category": "吃喝|排泄|睡眠|身体指标|里程碑|健康",
  "time": "HH:MM 或 now",
  "content": "具体内容描述",
  "photo": null
}
```

**查询回答 Prompt：**
```
根据以下宝宝记录数据，回答用户问题。
数据: {relevant_markdown_sections}
问题: {user_query}
用自然语言回答，包含具体数字和时间。
```

## 宝宝基础信息配置

首次使用时，Bot 引导用户设置宝宝基础信息，存储在 `baby/config.yaml`：

```yaml
name: "宝宝"           # 名字/昵称
birthday: "2025-09-16"  # 出生日期
gender: "男"            # 男/女，用于发育参考曲线
```

- `baby_age` 自动计算：当前日期 - birthday，格式 "X个月Y天"
- 月报发育评估：根据 gender 选择对应参考标准
- 名字用于报告中的称呼

后续可通过"修改宝宝信息"命令更新。

## MVP 范围

### ✅ 做的

1. 飞书 Bot 收发文字消息
2. 语音 → 飞书 ASR → 文字 → 同上流程
3. 图片 → 下载 → 存储 → 追问归类
4. 6 个维度的记录和追加（吃喝/排泄/睡眠/身体指标/里程碑/健康）
5. 当日/跨日查询
6. 每日自动创建 Markdown 文件
7. 日报自动生成 + 飞书推送
8. 周报/月报手动触发

### ❌ 不做的（后续迭代）

- 周报/月报自动生成（先手动触发，稳定后再开自动）
- 里程碑提醒（打疫苗、发育预期）
- 多宝宝支持
- Dataview 查询增强
- 邀请家庭成员共同记录

## 成功标准

1. 单手操作 10 秒内完成一条记录（语音输入）
2. 查询响应 5 秒内给出答案
3. 数据 100% 存在本地 Obsidian Vault，不依赖云端
4. 日报准确汇总当日所有维度数据
5. 连续使用 2 周不丢失任何记录
