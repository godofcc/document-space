## 核心摘要
该视频系统对比了5个主流的Agent记忆开源框架，包括Text2Mem、Mem0、Letta、ReMe和memU。Text2Mem定义了12个原子操作和五元JSON契约，提供记忆操作语言；Mem0是当前最流行的记忆中间件，支持17+LLM提供商、11+embedding模型、22+向量存储，分为语义记忆、情景记忆和程序记忆三种类型；Letta（原MemGPT）将OS虚拟内存思想搬进Agent架构，采用三层记忆（CORE、archival、recall），支持Git版本化记忆和Sleeptime异步后台学习；ReMe（阿里巴巴AgentScope出品）采用"文件即记忆"理念，记忆对用户完全透明可直接编辑；memU范式最激进，让记忆本身变成一个24/7后台主动Agent，采用双agent架构和显著性感知记忆机制。
