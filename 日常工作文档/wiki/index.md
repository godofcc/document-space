## 💡 Concepts（概念）

- [[多Agent协作]] — 通过多个 AI 智能体相互配合完成复杂任务的系统架构模式
- [[简单路由]] — 将用户问题直接转交给单个 Agent 全权处理的协作模式
- [[静态计划]] — 事先将问题拆分成计划表，依次安排 Agent 执行的协作模式
- [[动态监督]] — 由管理者实时判断并动态安排 Agent 行动的协作模式
- [[同伴交接]] — 去中心化、Agent 间相互委派任务的协作模式
- [[上下文管理]] — 在多轮交互中维护对话历史和任务状态的挑战
- [[工具污染]] — Agent 可用工具集包含不相关或误导性工具的问题
- [[浏览器自动化]] — 使用程序控制浏览器自动执行操作，替代人工完成重复性任务
- [[Skill]] — 将工作流程、经验和知识固化为可复用的技能，提升 AI Agent 执行效率
- [[Token 优化]] — 通过按需加载、Skill 复用、脚本固化等策略减少 AI Token 消耗的方法
- [[MCP]] — Model Context Protocol，用于将工具和数据接入 AI Agent 的标准协议
- [[无头浏览器]] — 没有图形界面的浏览器，在后台静默运行
- [[Persistent]] — 将浏览器状态持久化到磁盘，供后续会话复用
- [[自动化测试]] — 使用程序自动对软件进行测试，验证功能是否按预期工作
- [[Agent记忆]] — 让Agent能够跨对话、跨会话记住用户信息和历史状态的核心模块
- [[记忆框架]] — 为Agent提供记忆能力的软件系统，不同框架采用不同的设计理念和实现方式
- [[语义记忆]] — 关于世界、概念和事实的知识，不依赖于特定的时间和空间背景
- [[情景记忆]] — 关于个人经历的具体事件记忆，与特定的时间、地点、情感背景相关联
- [[程序记忆]] — 关于"如何做"的记忆，在Agent场景中对应agent执行的完整步骤
- [[虚拟内存]] — 操作系统内存管理的核心技术，将物理内存和磁盘空间结合
- [[Git版本化记忆]] — 将Git的版本控制思想应用于记忆管理，实现完整历史追踪
- [[Sleeptime异步后台学习]] — 在用户不交互的时候持续自我改进的agent
- [[文件即记忆]] — 将记忆直接存储为markdown文件的理念，让记忆对用户完全透明
- [[主动Agent记忆]] — 让记忆系统不再等待用户指令，而是主动运行的agent范式
- [[推理模型]] — 通过思维链进行中间推理步骤再输出答案的模型范式
- [[思维链]] — 让模型在给出最终答案前展开中间推理步骤的技术（CoT）
- [[有监督微调]] — 使用标注数据让基础模型学会遵循用户指令的训练方法（SFT）
- [[RLHF]] — 基于人类反馈的强化学习，让模型对齐人类偏好
- [[测试时计算]] — 模型在推理阶段投入更多计算和时间以提升正确率
- [[冷启动]] — 用少量高质量推理数据微调基础模型，让模型学会推理格式
- [[结果奖励vs过程奖励]] — 强化学习中两种奖励方案：结果奖励仅验证最终答案，过程奖励逐步评估推理链
- [[拒绝采样]] — 用增强后的模型生成数据再过滤筛选得到高质量样本
- [[规模法则]] — 模型规模越大能力越强的观察规律
- [[文生视频]] — 根据文字提示词生成视频内容的技术，计算量远超文本和图像生成
- [[准入控制]] — 在资源受限场景下通过多层级策略筛选请求进入系统的机制
- [[DAG工作流]] — 将复杂多阶段任务建模为有向无环图的编排方式
- [[Gang Scheduling]] — 要求一组资源同时分配同时释放的多资源联合调度策略
- [[服务降级]] — 资源不足时通过降低服务质量或限制部分用户来保护核心可用性
- [[Diffusion Transformer]] — 结合扩散模型去噪能力和Transformer全局注意力的视频生成架构
- [[提示词增强]] — 将简短关键词扩展改写为丰富描述以提升生成质量的预处理步骤
- [[超分辨率]] — 使用AI模型将低分辨率视频提升到更高分辨率的后处理技术
