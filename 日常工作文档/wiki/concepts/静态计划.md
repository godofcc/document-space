## 定义

静态计划是一种多 Agent 协作模式，通过事先将用户问题拆分成结构化的计划表，依次安排不同的 Agent 执行计划中的各项任务。

## 关键信息

**工作流程：**
1. 接收用户任务
2. 将任务拆解为子任务列表
3. 为每个子任务分配执行 Agent
4. 按顺序执行子任务
5. 直到所有任务完成

**核心特点：**
- 事前规划：在执行前完成任务分解和分配
- 顺序执行：按计划表依次执行
- 责任明确：每个 Agent 负责特定的子任务

**优势：**
- 执行路径清晰可控
- 便于追踪和调试
- 适合流程化的任务

**局限性：**
- 缺乏动态调整能力
- 难以应对执行中的突发情况
- 计划质量依赖初始分解准确性
