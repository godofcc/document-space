## 定义

有监督微调（Supervised Fine-Tuning, SFT）是一种使用标注数据让预训练基础模型学会遵循用户指令的训练方法。通过引入角色标签（`<system>`、`<user>`、`<assistant>`），让模型区分对话中的不同角色，从而能够对用户像助手一样给出回复。

## 关键信息

### SFT 的工作原理
- 在 prompt 模板中添加角色标签，让模型知道何时该输出
- 只在 `<assistant>` 部分计算 loss，前方 system 和 user prompt 做 zero out
- 训练过程与预训练阶段本质相同：移动一格文本，预测下一个 Token

### SFT 的应用场景
- 客服固定话术
- 特定领域的问答
- 知识注入（法律、医疗、公司内部知识库等）

### SFT 的局限性
- 依赖高质量标注数据（人工编写），难以规模化
- 遇到未见过的任务或要求，可靠性立即下降
- 只学到模板和套话，不能提升事实性和推理性回答
- 可能输出有害内容

### 在推理模型中的角色
- **Cold Start SFT**：用少量高质量推理数据微调基础模型，让模型学会使用 thinking/answer 标签格式
- **最终 SFT**：用拒绝采样后的高质量推理数据 + 非推理数据一起微调
