## 定义

简单路由是多 Agent 协作中的一种基础模式，将用户的问题直接转交给单个 Agent 进行全权处理，适合单一职责场景。

## 关键信息

**工作原理：**
- 接收用户问题
- 根据问题特征选择合适的 Agent
- 将问题路由到目标 Agent
- 由该 Agent 独立完成整个任务

**适用场景：**
- 任务相对简单明确
- 单个 Agent 能够独立完成
- 不需要多角色协作

**优势：**
- 实现简单
- 执行效率高
- 协调成本低

**局限性：**
- 无法发挥多 Agent 协作优势
- 难以处理复杂任务
- 缺乏灵活性和扩展性
