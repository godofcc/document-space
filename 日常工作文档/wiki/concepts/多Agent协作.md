## 定义

多 Agent 协作是一种通过多个 AI 智能体相互配合、分工合作来完成复杂任务的系统架构模式。每个 Agent 拥有特定的角色和职责，通过协作机制实现任务的路由、交接、执行和追踪。

## 关键信息

**核心价值：**
- 将复杂任务分解为子任务
- 发挥不同 Agent 的专长
- 提高系统的灵活性和可扩展性

**四种主要协作模式：**
1. **简单路由**：将用户问题转交给一个 Agent 全权处理
2. **静态计划**：事先将问题拆分成计划表，依次安排 Agent 执行
3. **动态监督**：由管理者判断并动态安排 Agent 行动
4. **同伴交接**：去中心化控制，Agent 之间相互委派任务

**面临的主要挑战：**
1. 上下文过多导致核心指令失效
2. 工具污染问题
3. 只分析不执行的注意力冲突
4. 任务终止异常

**优化方向：**
- 协作稳定性
- 任务交接质量
- 状态共享
- 运行时工具支持的完整性
- 可视化表达
