## 定义

同伴交接是一种去中心化的多 Agent 协作模式，摆脱了中心化控制，允许 Agent 之间相互委派任务，每个 Agent 都可以像中央 Agent 一样派发任务。

## 关键信息

**工作流程：**
1. 将任务下发给团队中的一个初始 Agent
2. 由该 Agent 分析任务并决定是否需要委派
3. 如果需要，选择合适的同伴 Agent 进行委派
4. 接收委派的 Agent 继续处理或进一步委派
5. 直到任务完成

**核心特点：**
- 去中心化：无单一控制节点
- 平等协作：所有 Agent 都有委派能力
- 灵活流转：任务在 Agent 间自由传递

**优势：**
- 最大化利用团队专长
- 更贴近人类团队协作模式
- 灵活性和适应性强

**挑战：**
- 输出格式要求严格
- 存在注意力冲突（分析和执行难以同时进行）
- 协调复杂度高

**解决方案：**
- 将任务拆分成多次交互
- 每次交互专注单一目标
- 保证每次执行的准确性
