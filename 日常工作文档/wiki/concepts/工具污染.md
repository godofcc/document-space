## 定义

工具污染是多 Agent 协作中的一个挑战，指 Agent 可用的工具集包含了与其职责不相关或在关键字上存在误导性匹配的工具，导致模型选择错误工具，影响执行效果。

## 关键问题

**污染的表现：**
- 工具在关键字上有某种匹配，但在业务上完全无关
- 模型被误导选择错误的工具
- 影响任务执行质量和效率

**产生原因：**
- 工具命名不当或含义模糊
- 给 Agent 安装了过多的技能包
- 缺乏针对性的工具配置

## 优化策略

**1. 遵循最小化原则**
- 只为每个 Agent 安装当前职责所需的工具
- 避免技能污染
- 确保工具集的专注性和相关性

**2. 提升模型工具选择能力**
- 优化工具描述和元信息
- 提供清晰的使用场景说明
- 改进工具调用的上下文理解
- 这是一个长期优化的过程

## 最佳实践

- 为不同角色 Agent 配置差异化的工具集
- 定期审查和清理不相关工具
- 建立工具使用的反馈机制
