## 定义

动态监督是一种更灵活的多 Agent 协作模式，由管理者 Agent 实时判断任务执行状态，动态决定下一步行动并安排相应 Agent 执行。

## 关键信息

**工作流程：**
1. 接收用户任务
2. 管理者 Agent 分析当前状态
3. 判断是否执行完毕
4. 思考下一步该做什么
5. 安排合适的 Agent 执行行动
6. 拿到结果后重复判断流程

**核心特点：**
- 动态决策：根据执行结果实时调整
- 灵活调度：管理者可自由选择 Agent
- 迭代优化：每次决策基于最新状态

**优势：**
- 高度灵活，适应性强
- 可应对执行中的变化
- 更接近真实工作流程

**挑战：**
- 依赖管理者的判断能力
- 决策链路复杂
- 需要大模型更强的动态决策能力
